# 如何增加新的文件格式

本文档说明如何为可靠性工具添加新的文件格式支持。

## 基本流程

1. 在 `core/file_parser.py` 中实现 `FileParser` 协议
2. 通过 `ParserManager.register()` 注册解析器
3. 在 `core/format_detector.py` 中添加格式检测规则（可选）

## FileParser 协议

```python
class FileParser(Protocol):
    def read(self, path: str) -> pd.DataFrame:
        ...

    @property
    def supported_extensions(self) -> list[str]:
        ...
```

返回的 DataFrame 必须包含 `PART_ID` 和 `SOFT_BIN` 列，其余列为测试项。

## 示例

参考 `core/column_mapper.py` 和 `tests/test_file_parser.py` 了解已有实现。

# UT 文件翻译

UT（Unit Test）文件是测试数据文件的一种特殊格式。
当用户在 FT 数据分析流程中同时选择了 UT 文件和其他标准文件时，
系统会自动识别并翻译 UT 文件中的测试列名，使其与标准 FT 格式兼容。

## UT 配置

在配置对话框的「UT配置」标签页中，用户可以配置 UT 文件的列名映射规则。

表格包含以下列：

| 列名 | 说明 | 示例 |
|------|------|------|
| 测试机台 | 测试设备型号 | T2000 |
| 原测试项 | UT 文件中的原始测试项名 | IGSS |
| input | 测试输入条件 | Vg=0 |
| condition | 测试条件 | 25C |
| output | 输出物理量 | I |
| 输出测试项 | 映射后的标准测试项名 | DC_IGSS |
| 备注 | 可选备注信息 | |

## 工作流程

1. 用户在 ConfigDialog 中配置 UT 映射规则，保存到配置文件中
2. 数据处理流程调用 `core/ut_translator.py` 中的 `translate_ut_files()`
3. 函数自动识别文件名包含 "UT" 或 "ut" 的文件
4. 对 UT 文件：读取数据，根据映射规则重命名测试列
5. 输出翻译后的临时 CSV 文件，与非 UT 文件合并后继续处理

## 识别规则

文件名中包含 `UT` 或 `ut` 子串的文件被视为 UT 文件。
例如：`UT_T2000_IGSS.csv`、`sample_ut_data.xlsx`

## 核心函数

```python
def translate_ut_files(
    file_paths: list[str],
    ut_config: list[dict],
    parser_manager: Optional[ParserManager] = None,
) -> list[str]:
```

- `file_paths`: 待处理的文件路径列表
- `ut_config`: UT 配置（从 `ConfigManager` 读取）
- `parser_manager`: 文件解析器管理器
- 返回：翻译后的文件路径列表（非 UT 文件原样保留）
